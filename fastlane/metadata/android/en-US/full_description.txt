<p>A remote-first network client built for Android TV. Every function is
operable with a TV remote, with an overscan-safe layout and clear focus states.</p>

<h3>Features</h3>

<ul>
<li>Connect / disconnect, server profiles and groups, subscriptions</li>
<li>Routing rules, DNS, per-app proxy and user assets</li>
<li>Connection testing, logs, configuration backup and restore</li>
<li>Settings, update check and open-source licenses</li>
<li>Config import without a camera: clipboard, a pairing-code LAN push from a
phone, document picker and a step-by-step wizard</li>
</ul>

<h3>Geoip and Geosite</h3>

<ul>
<li><code>geoip.dat</code> and <code>geosite.dat</code> are stored under
<code>Android/data/tv.roam.client/files/assets</code> (the path may differ on
some devices).</li>
<li>Rule data can be imported manually; third-party rule files are supported.</li>
</ul>

<h3>Development</h3>

<p>The Android project is in the <code>android/</code> Gradle directory. All
build tools live inside the repository under <code>.tooling/</code>; no
system-level environment variable is changed. Full toolchain versions, native
build steps and release reproduction are documented in
<code>docs/COMPLIANCE.md</code>.</p>
