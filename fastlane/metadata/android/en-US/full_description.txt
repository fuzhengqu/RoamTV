<p>RoamTV is an Xray/V2Ray proxy client for Android TV and Google TV. It
connects to a server or subscription you already have and is operated entirely
with a TV remote.</p>

<p>RoamTV does not provide proxy servers, accounts, or a VPN service.</p>

<h3>Television-first interface</h3>

<ul>
<li>D-pad navigation with visible focus states and a 5% overscan-safe layout.</li>
<li>OK selects, Back returns one level, Menu opens the actions for the focused
item.</li>
<li>Home keeps Connect, Test, Edit, QR, subscription update, and Delete together
in one action pane.</li>
</ul>

<h3>Servers and subscriptions</h3>

<ul>
<li>Manual profiles and groups, subscription groups, search, sorting, latency
test, and live speed.</li>
<li>VLESS (including Reality/XTLS), VMess, Shadowsocks, Trojan, WireGuard,
MASQUE (+WARP), SOCKS and HTTP through the bundled Xray core.</li>
<li>Custom outbound JSON import and full custom client configurations.</li>
<li>Routing rules, DNS, per-app proxy, and geoip/geosite asset files. A
ruleset can also be imported from an HTTP/HTTPS URL in the clipboard.</li>
<li>Monet dynamic colour in Settings on Android 12+.</li>
<li>VPN, proxy-only, and root modes.</li>
</ul>

<h3>Import without a camera</h3>

<ul>
<li>Clipboard, local file, document picker, and a step-by-step wizard.</li>
<li>The TV shows a QR code; the phone sends the encrypted configuration over the
local network with a one-time pairing code.</li>
</ul>

<h3>Operations</h3>

<ul>
<li>Connection logs with level selection and search.</li>
<li>Configuration backup and restore through the system document picker.</li>
<li>Update check, open-source licenses, and bundled Xray / hev-socks5-tunnel
versions.</li>
</ul>

<h3>Requirements</h3>

<ul>
<li>Android 8.0 (API 26) or newer on a TV, Google TV device, or Android TV box.</li>
<li>Your own proxy server or subscription. RoamTV does not sell or operate
servers.</li>
</ul>

<h3>Protocol note</h3>

<p>The server editor keeps Hysteria2 fields and share-link parsing for
compatibility with imported configurations, but the bundled Xray core does not
provide a Hysteria2 outbound. Use VLESS, VMess, Shadowsocks, Trojan, WireGuard,
SOCKS, or HTTP for a working connection.</p>

<p>No analytics, advertising, or telemetry are included. RoamTV is free software
under GPLv3; source and build instructions are in the GitHub repository.</p>
