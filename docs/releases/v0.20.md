# RoamTV v0.20 / 兼容性与合规收尾

## 中文

### 主要更新

- 关于页面新增「法律声明」入口：
  - 完整的 GNU GPLv3 许可证文本；
  - RoamTV 修改声明与上游归属；
  - SJCL 的 BSD-2-Clause 许可证；
  - 原有第三方开源许可证列表继续保留。
- 1.3x 字体适配加固：
  - 设置行、侧栏项、服务器行、分应用行和资源行改用最小高度，文字可增长；
  - 设置行和侧栏文字允许两行显示，减少 1.3x 字体下的截断。
- 发布流程新增 `RoamTV-<tag>-source.zip` 源码归档，包含子模块源码和随包原生二进制，满足 GPLv3 对应源码要求。
- 修正 README、F-Droid 商店描述中的资源文件路径：资源位于应用私有
  `app_assets` 目录，通过「资源文件」页面管理。
- 其他无障碍/布局基础调整和文档同步。

### 验证情况

- 192 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 1920×1080、320dpi 的 Android 17 模拟器上验证：
  - 全新安装后的首页布局和侧栏；
  - 设置页、法律声明入口和关于页；
  - 1.3x 字体下的首页与设置页截图；
  - M5 的设置、备份、日志、关于和更新功能。
- 主机环境和模拟器在收尾阶段多次异常退出，部分运行时检查未完成。

### 已知限制 / Not run

- 720p、4K、RTL、TalkBack、API 26–36 和物理电视/手机验证未完成。
- 1.3x 字体下的完整焦点遍历、对话框和所有页面未逐一验证。
- 主机重启后 TV 模拟器系统服务不稳定，部分截图和焦点检查无法重复。
- 服务运行中离开设置页触发单次重启仍未验证。
- WebDAV 上传/下载、TV 分享目标、root 模式未验证。

### 安装说明

- 普通用户下载 `RoamTV_0.20_universal.apk`；F-Droid 用户下载
  `RoamTV_0.20-fdroid_universal.apk`。
- 已安装 v0.10 的用户可以直接升级；源码 `versionCode` 为 20，Play Store
  APK 的实际 manifest code 为 4,000,020。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v0.20-source.zip`。

## English

### Highlights

- New Legal notices entry on the About screen:
  - the complete GNU GPLv3 license text;
  - the RoamTV modification notice and upstream attribution;
  - the SJCL BSD-2-Clause license;
  - the existing third-party license list remains available.
- 1.3x font hardening:
  - settings rows, rail items, server rows, per-app rows and asset rows use a
    minimum height so content can grow;
  - settings and rail labels can use two lines to reduce truncation at 1.3x.
- The release workflow now attaches `RoamTV-<tag>-source.zip`, containing the
  submodule sources and vendored native binaries required by GPLv3.
- Corrected the asset path in the README and F-Droid listing: assets live in
  the app-private `app_assets` directory and are managed from the Asset files
  screen.
- Additional layout/accessibility groundwork and documentation sync.

### Verification

- 192 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on a 1920x1080, 320dpi Android 17 emulator:
  - fresh-install Home layout and rail;
  - the Settings screen, Legal notices entry and About screen;
  - 1.3x Home and Settings screenshots;
  - the M5 settings, backup, log, about and update features.
- The host and emulator failed repeatedly near the end of the pass, so some
  runtime checks were not completed.

### Known limitations / Not run

- 720p, 4K, RTL, TalkBack, API 26-36 and physical TV/phone verification are
  not complete.
- Full 1.3x focus traversal, dialogs and every screen were not verified
  individually.
- The TV emulator's system services were unstable after the host restart, so
  some screenshots and focus checks could not be repeated.
- The single restart when leaving Settings with a running service is still
  unverified.
- WebDAV upload/download, TV share targets and root mode are unverified.

### Installation

- Regular users should download `RoamTV_0.20_universal.apk`; F-Droid users
  should download `RoamTV_0.20-fdroid_universal.apk`.
- Users on v0.10 can upgrade directly; the source `versionCode` is 20 and the
  Play Store APK manifest code is 4,000,020.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v0.20-source.zip`.
