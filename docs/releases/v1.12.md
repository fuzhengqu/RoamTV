# RoamTV v1.12 / 按钮居中与“更多”页面

## 中文

### 主要更新

- 修复按钮文字上下不居中。
  - 按钮内容区改为 `fillMaxHeight` 并在内容区垂直居中；
  - 按钮上下 content padding 设为 0，只保留左右 16dp；
  - “连接/断开”“测试”“编辑配置”“二维码”“更新订阅”“删除”“导入”“添加节点”“批量”统一生效。
- “更多”从弹窗改为右侧内容页。
  - 新增顶层路由 `More`，侧栏“更多”和首页、设置一样切换右侧内容；
  - 右侧显示日志、备份与还原、检查更新、关于四个入口；
  - 点击入口进入原来的工具页面，Back 回到“更多”页，再按 Back 回首页；
  - 删除原来的“更多”弹窗。
- 修复列表第一项焦点圈上沿被遮挡。
  - 订阅分组、路由设置、资源文件、分应用设置和日志列表增加 6dp 顶部内容留白；
  - 第一项焦点圈不再被列表视口裁掉。

### 真实电视验证

设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，1920×1080 逻辑分辨率。

- 首页“批量”等按钮的文字在按钮内垂直居中；
- “更多”页在右侧正常显示 Logcat、备份与还原、检查更新、关于，不再弹窗；
- 点击 Logcat 进入工具页，Back 返回“更多”，再 Back 回首页；
- 侧栏“更多”保持选中状态。

### 验证

- 206 个 JVM 单元测试通过，0 失败。
- `lintPlaystoreDebug` 通过，`assemblePlaystoreDebug` 和签名 release 通过。
- 发布 APK 为 `armeabi-v7a`，`versionName=1.12`，manifest `versionCode=4,000,112`。

### 已知限制 / Not run

- 订阅分组、路由设置、资源文件、分应用设置、日志列表的第一项焦点圈上沿在 v1.12 未逐页截图确认（已统一增加顶部留白）。
- 720p、4K、阿拉伯语 RTL、1.3x 字体下的新按钮/更多页未逐一验证。
- 物理手机连续导入、TalkBack、WebDAV 真实服务器、TV 分享目标和 root 模式未验证。

### 安装说明

- 普通用户下载 `RoamTV_1.12_armeabi-v7a.apk` 或 `RoamTV_1.12_universal.apk`。
- 已安装 v1.11 的用户可以直接升级；源码 `versionCode` 为 112，Play Store
  APK 的实际 manifest code 为 4,000,112。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.12-source.zip`。

## English

### Highlights

- Fixed vertical text centering in buttons.
  - Button content now fills the available height and is centered vertically;
  - vertical content padding is zero while horizontal padding stays at 16dp;
  - this applies to Connect/Disconnect, Test, Edit, QR, Update subscription,
    Delete, Import, Add node and Batch.
- "More" is now a right-hand content page instead of a dialog.
  - A new top-level `More` route makes the rail item behave like Home and
    Settings;
  - the right side lists Logcat, Backup & Restore, Check for update and About;
  - selecting an entry opens the existing tool page; Back returns to More and
    then Home;
  - the old More dialog was removed.
- Fixed the clipped top edge of the first list item's focus ring.
  - Subscriptions, Routing, Assets, Per-app and Logcat lists now have 6dp top
    content padding.

### Real TV verification

Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, 1920x1080
logical resolution.

- Home button labels (including Batch) are vertically centered.
- The More page shows Logcat, Backup & Restore, Check for update and About on
  the right, with no dialog.
- Selecting Logcat opens the tool page; Back returns to More and then Home.
- The More rail item stays selected while its page is open.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- The published APK is `armeabi-v7a` with `versionName=1.12` and manifest
  `versionCode=4,000,112`.

### Known limitations / Not run

- The first-item focus ring top edge in Subscriptions, Routing, Assets,
  Per-app and Logcat was not screenshotted individually for v1.12 (the shared
  top padding was added).
- The new button and More page were not checked at 720p, 4K, Arabic RTL or
  1.3x font.
- Multi-import from a physical phone, TalkBack, a live WebDAV server, TV share
  targets and root mode were not verified.

### Installation

- Regular users should download `RoamTV_1.12_armeabi-v7a.apk` or
  `RoamTV_1.12_universal.apk`.
- Users on v1.11 can upgrade directly; the source `versionCode` is 112 and the
  Play Store APK manifest code is 4,000,112.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.12-source.zip`.
