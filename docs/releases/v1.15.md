# RoamTV v1.15 / 品牌图标与文档更新

## 中文

### 主要更新

- **新应用图标**：采用提供的方形插画（电视 + 地球 + 长城/阶梯），保留原品牌蓝。
  - 自适应图标前景缩放到 66/108 安全区，圆形、圆角和方形遮罩下都不会裁掉
    电视/地球主体；
  - 补齐 48/72/96/144/192px 传统图标和圆形图标；
  - Android 13 单色图标改为“电视 + 地球”矢量；
  - 侧栏左上角换成新的 32dp 简化标志。
- **电视横幅**：改为真正的 16:9 位图横幅（160×90 到 640×360），左侧方形标志，
  右侧 `RoamTV` 和 `Android TV proxy client`；不再用自适应图标充当横幅。
- **商店图标**：`fastlane` 更新为 512×512 新图标。
- **UI 基线冻结**：新增 `docs/UI_BASELINE.md`，把 v1.14 的布局、间距、按钮、
  焦点、更多页和返回焦点规则固定下来；`ui/AGENTS.md` 增加对应的硬规则。
  本版本只改品牌资源，不改 v1.14 的页面布局。
- **README / GitHub / fastlane 文案**：明确这是 Android TV / Google TV 的
  Xray 代理客户端，需要自备服务器或订阅，不提供节点、账号或 VPN 服务；
  补充适用对象、协议、ABI、安装、手机导入、隐私和限制说明。

### 协议说明

内置 Xray 核心支持 VLESS（含 Reality/XTLS）、VMess、Shadowsocks、Trojan、
WireGuard、SOCKS 和 HTTP 出站。编辑器和分享链接解析仍保留 Hysteria2 字段，
但内置 Xray 核心没有 Hysteria2 出站；实际连接请使用上述协议。

### 验证

- 206 个 JVM 单元测试通过，0 失败。
- `lintPlaystoreDebug` 通过，`assemblePlaystoreDebug` 和签名 release 通过。
- 在 Android TV 模拟器（API 36，1080p）上检查电视桌面横幅、侧栏 32dp 标志，
  以及 v1.14 首页/设置/更多/路由/资源页布局未变化；用 1280x720dp 重新检查了
  首页和侧栏。
- 自适应/圆形/单色资源均已编译；在 192px 下预览了圆形、圆角和方形遮罩。
  电视桌面只显示横幅，未在主题图标启动器上渲染单色层。
- 未在物理电视上安装本次构建，因为电视正在使用；没有改动电视上已有的节点、
  订阅和连接状态。

### 已知限制 / Not run

- Hysteria2 仍不能通过内置 Xray 核心连接；TUIC 未实现。
- 未逐一测试 VMess、SS、Trojan、WireGuard 真实服务器。
- 720p 仅重新检查了首页和侧栏布局；4K、RTL、1.3x、TalkBack、WebDAV 和
  root 模式沿用上一版记录，本次没有重新执行。

### 安装说明

- 普通用户下载 `RoamTV_1.15_armeabi-v7a.apk` 或
  `RoamTV_1.15_universal.apk`。
- 已安装 v1.14 的用户可以直接升级；源码 `versionCode` 为 115。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.15-source.zip`。

## English

### Highlights

- **New launcher artwork**: the supplied square illustration (television,
  globe, Great Wall/ladder) keeps the original brand blue.
  - The adaptive foreground is scaled into the 66/108 safe zone so circular,
    rounded and square masks keep the television and globe intact.
  - Added 48/72/96/144/192px legacy and round icons.
  - The Android 13 monochrome layer is now a television + globe vector.
  - The 32dp sidebar mark uses the new artwork.
- **TV banner**: a real 16:9 bitmap banner (160x90 through 640x360) with the
  square mark on the left and `RoamTV` / `Android TV proxy client` on the right.
  The adaptive icon is no longer used as the banner.
- **Store icon**: the fastlane listing now uses the new 512x512 artwork.
- **Frozen UI baseline**: `docs/UI_BASELINE.md` records the v1.14 layout,
  spacing, buttons, focus, More page and back-focus rules; `ui/AGENTS.md` adds
  the matching hard rules. This release changes branding only, not the v1.14
  page layout.
- **README / GitHub / fastlane copy**: states that RoamTV is an Android TV /
  Google TV Xray client that requires an existing server or subscription and
  does not provide servers, accounts, or a VPN service. Adds audience,
  protocols, ABIs, installation, phone import, privacy, and limitations.

### Protocol note

The bundled Xray core carries VLESS (including Reality/XTLS), VMess,
Shadowsocks, Trojan, WireGuard, SOCKS and HTTP outbounds. The editor and
share-link parser still keep Hysteria2 fields, but the bundled core has no
Hysteria2 outbound. Use the protocols above for a working connection.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- On an API 36 1080p Android TV emulator, the TV launcher banner and 32dp sidebar
  mark render, and the Home, Settings, More, Routing and Assets layouts remain
  the v1.14 layout; Home and the rail were rechecked at 1280x720dp.
- The adaptive, round and monochrome resources compile; circle, rounded-square
  and square masks were previewed at 192px. The TV launcher uses the banner and
  does not render the monochrome layer, so themed-icon rendering was not run.
- This build was not installed on the physical TV because it was in use; its
  existing nodes, subscriptions and connection state were not changed.

### Known limitations / Not run

- Hysteria2 still cannot connect through the bundled Xray core; TUIC is not
  implemented.
- VMess, SS, Trojan and WireGuard live servers were not individually exercised.
- Only the Home and rail layout was rechecked at 720p; 4K, RTL, 1.3x,
  TalkBack, WebDAV and root retain the previous record and were not re-run.

### Installation

- Regular users should download `RoamTV_1.15_armeabi-v7a.apk` or
  `RoamTV_1.15_universal.apk`.
- Users on v1.14 can upgrade directly; the source `versionCode` is 115.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.15-source.zip`.
