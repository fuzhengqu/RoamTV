# RoamTV v0.02 / 路由设置与规则编辑

## 中文

### 主要更新

- 新增 TV 路由设置：域策略、规则列表、规则编辑器和规则启用状态。
- 新增路由规则字段：备注、启用、锁定、domain、ip、process、port、protocol、
  network 和 outboundTag。
- 支持新增、编辑和保存路由规则；保存后立即回到列表并刷新。
- 支持从手机配对页把 domain/ip/process/protocol 发送到电视。
- 规则列表显示 outboundTag 和启用状态，锁定的规则使用锁图标。
- 提供预设导入、剪贴板导入和剪贴板导出入口；这些路径尚未在模拟器上完整验证。

### 验证情况

- 174 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 37 TV 模拟器上验证了：
  - 路由列表加载现有规则
  - 域策略从 AsIs 切换到 IPIfNonMatch
  - 新增 `TestRule`（domain=example.com）并保存
  - More 对话框的导入/导出入口
- 签名 APK 在 API 37 设备上安装成功。

### 已知限制

- 规则删除、预设导入、剪贴板导入/导出尚未端到端验证。
- 路由规则对实际连接的影响尚未验证。
- 进程包选择器属于 M4c，当前只能手动输入包名。
- 分应用代理、资源文件、设置、备份、日志、关于和更新检查尚未完成。
- 尚未在物理电视和物理手机上验证；API 26–36、RTL、TalkBack、4K 和
  1.3x 字体尚未验证。

### 安装说明

- 普通用户下载 `RoamTV_0.02_universal.apk`；F-Droid 用户下载
  `RoamTV_0.02-fdroid_universal.apk`。
- 已安装 v0.01 的用户可以直接升级；源码 `versionCode` 为 2，Play Store
  APK 的实际 manifest code 为 4,000,002。
- 如果之前安装过 debug 构建，请先卸载；debug 与 release 签名不同。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。

## English

### Highlights

- New TV routing settings: domain strategy, rule list, rule editor and enabled
  state.
- New routing fields: remarks, enabled, locked, domain, ip, process, port,
  protocol, network and outboundTag.
- Add, edit and save routing rules; saving returns to the list and refreshes it.
- Send domain/ip/process/protocol values from the phone pairing page to the TV.
- The list shows the outbound tag and enabled state; locked rules use a lock
  icon.
- Preset import, clipboard import and clipboard export entries are present;
  those paths have not been fully exercised on the emulator.

### Verification

- 174 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on an API 37 TV emulator:
  - the routing list loads existing rules;
  - the domain strategy changes from AsIs to IPIfNonMatch;
  - a new `TestRule` with `domain=example.com` is saved;
  - the More dialog exposes the import/export entries.
- The signed APK installs successfully on an API 37 device.

### Known limitations

- Rule deletion, preset import and clipboard import/export were not verified
  end to end.
- The runtime effect of routing rules on a live connection was not verified.
- The process package picker belongs to M4c; the process field is manual for
  now.
- Per-app proxy, user assets, settings, backup, logs, about and update checks
  are not implemented yet.
- Not yet verified on a physical TV or phone, API 26-36, RTL, TalkBack, 4K or
  1.3x font scale.

### Installation

- Regular users should download `RoamTV_0.02_universal.apk`; F-Droid users
  should download `RoamTV_0.02-fdroid_universal.apk`.
- Users on v0.01 can upgrade directly; the source `versionCode` is 2 and the
  Play Store APK manifest code is 4,000,002.
- Uninstall any previous debug build first; debug and release builds use
  different signing keys.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
