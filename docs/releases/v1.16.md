# RoamTV v1.16 / 首行焦点框修复

## 中文

### 修复内容

- 修复 **备份与还原** 页面第一行 `备份配置` 顶部圆角和焦点环被裁切的问题。
- 修复 **关于** 页面第一行 `开源许可` 顶部圆角和焦点环被裁切的问题。
- 同一模式还存在于以下页面，本次一并修复：
  - 策略组编辑器
  - 代理链编辑器
  - 订阅编辑器
  - 资源文件编辑器
- 新增共享组件 `TvSettingsColumn`：在滚动内容顶部保留 6dp 余量，第一行可聚焦时不会再被滚动容器上边缘裁切。
- 在 `ui/AGENTS.md` 和 `docs/UI_BASELINE.md` 增加硬规则：任何滚动列表只要第一项可聚焦，必须预留 6dp 顶部间距；优先使用 `TvSettingsColumn`。
- 页面布局、字体、间距和导航行为没有其他变化；v1.14 UI 基线继续有效。

  - 类型选择对话框第一项焦点环完整。

## English

### Fixes

- Fixed the clipped top corners and focus ring on the first row of
  **Backup & Restore** (`Backup config`).
- Fixed the clipped top corners and focus ring on the first row of **About**
  (`Open-source licenses`).
- The same pattern existed in these screens and is fixed as well:
  - Policy group editor
  - Proxy chain editor
  - Subscription editor
  - User asset editor
- Added the shared `TvSettingsColumn` component. It reserves 6dp of top content
  padding so the first focusable row is not clipped by the scroll viewport.
- Added a hard rule to `ui/AGENTS.md` and `docs/UI_BASELINE.md`: any scroll list
  whose first child can take focus must reserve 6dp of top spacing and should
  use `TvSettingsColumn`.
- No other layout, typography, spacing or navigation change; the v1.14 UI
  baseline remains in effect.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` passes.
- API 36 TV emulator at 1080p:
  - the first row of `Backup & Restore` has a complete four-corner focus ring;
  - the first row of `About` has a complete four-corner focus ring;
  - the first row of the asset editor and policy group editor is complete;
  - the first option in the type picker dialog is complete.
- API 36 TV emulator at 1280x720dp: the first row of `About` is complete.
- This build has not been installed on the physical TV yet; once the TV is free,
  install it, recheck Backup, About and the editor first rows, then publish.

### Installation

- Regular users should download `RoamTV_1.16_armeabi-v7a.apk` or
  `RoamTV_1.16_universal.apk`.
- Users on v1.15 can upgrade directly; the source `versionCode` is 116.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.16-source.zip`.
