# RoamTV v1.14 / Xray-core 26.11.9 更新

## 中文

### 主要更新

- 更新内置 Xray-core 到 **26.11.9**（AndroidLibXrayLite `v26.11.9`）。
  - 包含 Chrome 155+ 指纹、XDRIVE transport 等上游更新；
  - `libv2ray.aar` 重新下载，包含 `armeabi-v7a`、`arm64-v8a`、`x86`、`x86_64` 四个 ABI；
  - About 页的 Xray 版本来自核心运行时，升级后自动显示新版本。
- HEV 仍为 **2.19.3**，本次按“只更新 Xray”的要求未升级。
- 未引入 sing-box；当前客户端仍只使用 Xray + HEV TUN。

### 真实电视验证

设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，1920×1080 逻辑分辨率。

- v1.14 安装后启动正常；
- logcat 显示新核心：
  - `V2Ray core environment initialized successfully`
  - `[Warning] core: Xray 26.11.9 started`
- 连接真实节点成功，首页显示：
  - `连接成功：延时 203 ms`
  - 代理速度 `↑ 180.0 B/s ↓ 0.0 B/s`
- 首页布局、操作栏、返回焦点和原有 v1.13 修复保持不变。

### 验证

- 206 个 JVM 单元测试通过，0 失败。
- `lintPlaystoreDebug` 通过，`assemblePlaystoreDebug` 和签名 release 通过。
- 发布 APK 为 `armeabi-v7a`，`versionName=1.14`，manifest `versionCode=4,000,114`。

### 已知限制 / Not run

- HEV 2.20.0 未升级（本次只更新 Xray）。
- 未逐一测试 VMess、SS、Trojan、Hysteria2、WireGuard 真实服务器；本次用 VLESS 真实节点验证核心启动和连接。
- 720p、4K、RTL、1.3x、物理手机连续导入、TalkBack、WebDAV 和 root 模式未验证。

### 安装说明

- 普通用户下载 `RoamTV_1.14_armeabi-v7a.apk` 或 `RoamTV_1.14_universal.apk`。
- 已安装 v1.13 的用户可以直接升级；源码 `versionCode` 为 114，Play Store
  APK 的实际 manifest code 为 4,000,114。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.14-source.zip`。

## English

### Highlights

- Updated the embedded Xray-core to **26.11.9** (AndroidLibXrayLite
  `v26.11.9`).
  - Includes upstream Chrome 155+ fingerprint and XDRIVE transport changes;
  - the `libv2ray.aar` was replaced and contains `armeabi-v7a`, `arm64-v8a`,
    `x86` and `x86_64`;
  - the About screen reads the Xray version from the running core.
- HEV remains **2.19.3** because this update only covers Xray.
- sing-box is not included; the client still uses Xray + HEV TUN only.

### Real TV verification

Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, 1920x1080
logical resolution.

- v1.14 installs and launches.
- logcat shows the new core:
  - `V2Ray core environment initialized successfully`
  - `[Warning] core: Xray 26.11.9 started`
- A real node connected successfully; the Home header showed
  `Connection successful: 203 ms` and `Proxy ↑ 180.0 B/s ↓ 0.0 B/s`.
- The Home layout, action pane, Back focus and previous v1.13 fixes remain.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- The published APK is `armeabi-v7a` with `versionName=1.14` and manifest
  `versionCode=4,000,114`.

### Known limitations / Not run

- HEV 2.20.0 was not upgraded (Xray only).
- VMess, SS, Trojan, Hysteria2 and WireGuard live servers were not exercised;
  a real VLESS node verified startup and connection.
- 720p/4K/RTL/1.3x, physical phone multi-import, TalkBack, WebDAV and root were
  not verified.

### Installation

- Regular users should download `RoamTV_1.14_armeabi-v7a.apk` or
  `RoamTV_1.14_universal.apk`.
- Users on v1.13 can upgrade directly; the source `versionCode` is 114 and the
  Play Store APK manifest code is 4,000,114.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.14-source.zip`.
