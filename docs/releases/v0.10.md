# RoamTV v0.10 / 设置、备份与信息页面

## 中文

### 主要更新

- 完整 TV 设置页面：
  - 界面：速度显示、删除确认、显示“全部”分组、语言；
  - VPN：IPv6、Prefer IPv6、本地 DNS、FakeDNS、VPN DNS、HTTP 代理、
    Bypass LAN、接口地址、MTU、HEV TUN、HEV 日志级别和读写超时；
  - 核心：Sniffing、routeOnly、本地代理、局域网共享、动态 SOCKS 端口、
    SOCKS 端口/用户名/密码/UDP、远程 DNS、直连 DNS、DNS 映射、核心日志
    等级、出站域名解析方式；
  - Mux、Fragment、Observatory 的完整参数；
  - 高级：开机连接、系统 VPN 设置、延迟测试 URL、真实延迟并发数、
    连接信息测试 URL；
  - 模式：VPN / 仅代理、root 模式、root 局域网共享。
- 设置项会立即保存；依赖项会根据当前模式自动置灰，例如 Proxy only 下
  禁用 VPN 专属选项，FakeDNS 需要本地 DNS，Mux/Fragment 子项跟随开关。
- 离开设置页面时，如果服务正在运行，只重启一次连接；分组列表同步刷新。
- 新增 TV 备份与恢复：
  - 本地备份通过系统文件选择器保存 zip；
  - 从本地 zip 恢复，成功后重新初始化设置并刷新分组；
  - 分享配置 zip；
  - 修复未使用的配置存储；
  - WebDAV 服务器地址、用户名、密码和远程目录编辑。
- 新增 TV 日志页面：日志列表、搜索、复制全部、刷新、清空，单行点击复制。
- 新增 TV 关于页面：GPL 归属说明、开源许可证全文、翻译者名单、
  应用版本、原生库版本和应用 ID。
- 新增 TV 更新检查：预发布开关、检查更新、版本信息；发现新版本时显示
  更新说明和下载入口。

### 验证情况

- 191 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 37 TV 模拟器上验证了：
  - 设置页完整分组、开关、下拉框、文本编辑、依赖置灰、语言切换和
    系统 VPN 设置跳转；
  - 本地备份写入 Downloads、从该 zip 恢复成功；
  - WebDAV 编辑器和无 URL 时禁用保存；
  - 日志列表、搜索对话框；
  - 关于页、开源许可证和翻译者对话框；
  - 更新检查完成并进入“已是最新版本”状态。
- `SettingsStateTest`、`SettingsViewModelTest`、`AboutViewModelTest` 覆盖
  设置依赖、Mux 解析、VPN 设置可用性、HTML 清理和翻译者列表。

### 已知限制

- 服务运行中离开设置页触发单次重启尚未验证。
- root 模式和 root 局域网共享尚未在真实 root 设备上验证。
- WebDAV 上传/下载未连接真实服务器验证。
- TV 上的备份分享目标、日志复制/清空、更新下载弹窗和浏览器打开尚未验证。
- 设置、备份和更新页面的 Activity 重建尚未验证。
- 尚未在物理电视和物理手机上验证；API 26–36、RTL、TalkBack、4K 和
  1.3x 字体尚未验证。

### 安装说明

- 普通用户下载 `RoamTV_0.10_universal.apk`；F-Droid 用户下载
  `RoamTV_0.10-fdroid_universal.apk`。
- 已安装 v0.04 的用户可以直接升级；源码 `versionCode` 为 10，Play Store
  APK 的实际 manifest code 为 4,000,010。
- 如果之前安装过 debug 构建，请先卸载；debug 与 release 签名不同。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。

## English

### Highlights

- Complete TV Settings screen:
  - UI: speed display, delete confirmation, All-group tab, language;
  - VPN: IPv6, prefer IPv6, local DNS, FakeDNS, VPN DNS, HTTP proxy,
    bypass LAN, interface address, MTU, HEV TUN, HEV log level and R/W timeout;
  - Core: sniffing, routeOnly, local proxy, LAN sharing, dynamic SOCKS port,
    SOCKS port/username/password/UDP, remote DNS, direct DNS, DNS mappings,
    core log level and outbound domain resolution;
  - full Mux, Fragment and Observatory parameters;
  - Advanced: connect on boot, system VPN settings, delay-test URL, real-ping
    concurrency and connection-info URL;
  - Mode: VPN / proxy-only, root mode and root LAN sharing.
- Settings save immediately. Dependent rows dim automatically: proxy-only mode
  disables VPN-only options, FakeDNS requires local DNS, and Mux/Fragment
  children follow their switches.
- Leaving Settings restarts a running service once and refreshes the group
  list.
- New TV backup and restore:
  - local backup to a zip through the system file picker;
  - restore from a local zip, then reinitialize settings and refresh groups;
  - share the configuration zip;
  - repair unused profile storage;
  - edit the WebDAV URL, username, password and remote directory.
- New TV Logcat screen: list, search, copy all, refresh and clear; tap a row to
  copy that line.
- New TV About screen: GPL attribution, full open-source license text,
  translators, app version, native library version and application ID.
- New TV update check: pre-release switch, check action, version info, and a
  release dialog with notes and a download entry.

### Verification

- 191 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on an API 37 TV emulator:
  - the full Settings groups, switches, dropdowns, text edits, dependency
    dimming, language switch and System VPN settings intent;
  - local backup to Downloads and a successful restore from that zip;
  - the WebDAV editor and its disabled Save state without a URL;
  - the Logcat list and search dialog;
  - the About, open-source license and translator dialogs;
  - update check completing at the already-latest state.
- `SettingsStateTest`, `SettingsViewModelTest` and `AboutViewModelTest` cover
  setting dependencies, Mux parsing, VPN settings availability, HTML cleanup
  and translator lines.

### Known limitations

- The single restart when leaving Settings with a running service was not
  verified.
- Root mode and root LAN sharing were not verified on a rooted device.
- WebDAV upload/download was not verified against a live server.
- TV share targets, log copy/clear, the new-version dialog and opening the
  download page were not verified.
- Activity recreation on the Settings, Backup and Update screens was not
  verified.
- Not yet verified on a physical TV or phone, API 26-36, RTL, TalkBack, 4K or
  1.3x font scale.

### Installation

- Regular users should download `RoamTV_0.10_universal.apk`; F-Droid users
  should download `RoamTV_0.10-fdroid_universal.apk`.
- Users on v0.04 can upgrade directly; the source `versionCode` is 10 and the
  Play Store APK manifest code is 4,000,010.
- Uninstall any previous debug build first; debug and release builds use
  different signing keys.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
