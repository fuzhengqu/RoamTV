# RoamTV v0.01 / 首个公开测试版

## 中文

### 主要更新

- 全新的 Android TV 界面：单 Activity、左侧导航、遥控器方向键/OK/返回操作、
  10-foot 布局和清晰的焦点边框。
- 首页：节点分组、节点列表、详情面板、连接/断开、VPN 授权、测试、搜索和
  维护操作。
- 导入中心：手机配对、剪贴板、本地文件、手动粘贴；手机页面使用 SJCL
  AES-GCM 加密后再通过局域网发送到电视。
- 分享：从首页为选中节点生成二维码。
- 节点编辑器：VMess、VLESS、Shadowsocks、SOCKS、HTTP、Trojan、WireGuard、
  Hysteria2 和自定义配置；策略组和代理链编辑器。
- 订阅：订阅列表、添加/编辑、全部更新、URL 与更新间隔校验、入口/出口代理。
- 语言：跟随系统或手动选择 10 种语言。
- Android 8–17（minSdk 26，targetSdk 37）。

### 验证情况

- 165 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 37 TV 模拟器上验证了遥控器导航、VPN 连接、导入中心、配对二维码、
  分享二维码、节点编辑器和订阅界面。
- 使用桌面 Chromium 完成了一次真实浏览器配对：二维码页面加载、SJCL 加密
  POST、电视导入节点成功。

### 已知限制

- 路由规则、分应用代理、资源文件、设置、备份、日志、关于和更新检查尚未
  完成，将在后续版本加入。
- 尚未在物理电视和物理手机上验证；尚未验证 API 26–36、RTL、TalkBack、
  4K 和 1.3x 字体。
- 仅验证了 VPN 模式；代理模式和 root 模式尚未验证。
- 测试节点延迟时，模拟器环境无法访问默认测试 URL，因此延迟结果未作为通过项。

### 安装说明

- 普通用户请下载 `RoamTV_0.01_universal.apk`；F-Droid 用户请下载
  `RoamTV_0.01-fdroid_universal.apk`。
- 也可以按设备 ABI 下载对应 APK，例如 `arm64-v8a` 或 `armeabi-v7a`。
- 如果之前安装过 debug 构建，请先卸载；debug 与 release 签名不同，无法覆盖安装。
- 每个 APK 都有对应的 `.sig` 文件，公钥为 `RoamTV-public-key.asc`。可使用
  `gpg --verify <apk>.sig <apk>` 校验。
- 源码中的 `versionCode` 为 1；由于现有 Play Store ABI 偏移，APK 清单中的
  `versionCode` 为 4,000,001（1 + 4,000,000）。后续版本继续按源码
  `versionCode` 递增。
- 本版本是首个公开测试版，请勿用于不可替代的生产环境。

## English

### Highlights

- A new Android TV interface: single Activity, left navigation, D-pad/OK/Back
  operation, 10-foot layout and visible focus rings.
- Home: groups, server list, detail pane, connect/disconnect, VPN consent,
  testing, search and maintenance actions.
- Import hub: phone pairing, clipboard, local file and manual paste. The phone
  page encrypts the payload with SJCL AES-GCM before sending it over the LAN.
- Sharing: generate a QR code for the selected server from Home.
- Server editors: VMess, VLESS, Shadowsocks, SOCKS, HTTP, Trojan, WireGuard,
  Hysteria2 and custom configurations; policy-group and proxy-chain editors.
- Subscriptions: list, add/edit, update-all, URL and interval validation, and
  entry/exit proxy selection.
- Language: follow the system or choose one of 10 locales manually.
- Android 8-17 (`minSdk 26`, `targetSdk 37`).

### Verification

- 165 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on an API 37 TV emulator: D-pad navigation, VPN connection, import
  hub, pairing QR, share QR, server editors and the subscriptions screen.
- Completed a real browser pairing run with desktop Chromium: the QR page
  loaded, the SJCL-encrypted POST was accepted, and the TV imported the server.

### Known limitations

- Routing rules, per-app proxy, user assets, settings, backup, logs, about and
  update checks are not implemented yet; they will follow in later versions.
- Not yet verified on a physical TV or phone, API 26-36, RTL, TalkBack, 4K or
  1.3x font scale.
- Only VPN mode was verified; proxy-only and root modes were not.
- The emulator could not reach the default latency-test URL, so latency results
  are not claimed as verified.

### Installation

- Regular users should download `RoamTV_0.01_universal.apk`; F-Droid users
  should download `RoamTV_0.01-fdroid_universal.apk`.
- You can also download the APK matching the device ABI, such as `arm64-v8a`
  or `armeabi-v7a`.
- Uninstall any previous debug build first; debug and release builds use
  different signing keys and cannot overwrite each other.
- Every APK has a matching `.sig` file; the public key is
  `RoamTV-public-key.asc`. Verify with `gpg --verify <apk>.sig <apk>`.
- The source versionCode is 1. Because of the existing Play Store ABI offset,
  the APK manifest versionCode is 4,000,001 (1 + 4,000,000). Future releases
  continue to increment the source versionCode.
- This is the first public test build. Do not use it for irreplaceable
  production work.
