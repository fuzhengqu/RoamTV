# RoamTV v0.04 / 用户资源文件

## 中文

### 主要更新

- 新增 TV 资源文件页面：内置 GeoIP、GeoSite 和 `geoip-only-cn-private.dat`
  行显示大小、修改时间和内置标记。
- 新增 Geo 文件来源选择：Loyalsoldier、runetfreedom 和 Chocolate4U；选择后
  会立即刷新内置资源地址，并在重启页面后保留。
- 新增资源 URL 编辑器：
  - 添加、编辑和删除自定义资源 URL；
  - 必填校验、重名校验和字段错误定位；
  - URL 字段支持“从手机发送”，复用现有 TV 配对流程。
- 新增本地文件导入：通过系统文件选择器（支持遥控器方向键）导入任意资源
  文件，自动复制到资源目录并显示文件大小和日期。
- 内置资源行不可编辑；本地文件行只提供查看和删除，避免误改文件名导致资源
  丢失。
- 新增“下载全部资源”：
  - 显示下载状态；
  - 优先使用当前代理端口，失败后回退直连；
  - 下载完成后刷新所有文件的大小和修改时间；
  - 临时文件下载成功后才替换正式文件。

### 验证情况

- 184 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 37 TV 模拟器上验证了：
  - 内置资源列表、大小和日期显示；
  - Geo 来源切换及跨页面持久化；
  - URL 资源的添加、编辑、删除；
  - 空字段校验与错误提示；
  - 通过 DocumentsUI 使用方向键导入本地文件并删除；
  - 下载全部资源后文件大小/日期更新；
  - URL 编辑器中的手机配对二维码与 6 位代码。
- `UserAssetEditorValidationTest` 覆盖必填、重名、合法输入和文件名清理；
  `TvNavigatorTest` 覆盖资源编辑器路由恢复。

### 已知限制

- 手机配对扫码后把 URL 自动填入资源字段的完整链路尚未端到端验证。
- 下载全部资源时的部分失败提示尚未验证。
- 从手机导入文件（当前通过系统文件选择器导入本地文件）尚未实现。
- 设置、备份/WebDAV、日志、关于和更新检查尚未完成。
- 尚未在物理电视和物理手机上验证；API 26–36、RTL、TalkBack、4K 和
  1.3x 字体尚未验证。

### 安装说明

- 普通用户下载 `RoamTV_0.04_universal.apk`；F-Droid 用户下载
  `RoamTV_0.04-fdroid_universal.apk`。
- 已安装 v0.03 的用户可以直接升级；源码 `versionCode` 为 4，Play Store
  APK 的实际 manifest code 为 4,000,004。
- 如果之前安装过 debug 构建，请先卸载；debug 与 release 签名不同。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。

## English

### Highlights

- New TV Asset files screen: built-in GeoIP, GeoSite and
  `geoip-only-cn-private.dat` rows show size, modification time and a built-in
  marker.
- Geo file source selection: Loyalsoldier, runetfreedom and Chocolate4U. A
  change refreshes the built-in URLs immediately and persists across screen
  visits.
- New asset URL editor:
  - add, edit and delete custom asset URLs;
  - required-field validation, duplicate-name validation and focus on the
    failing field;
  - the URL field supports "From phone" through the existing TV pairing flow.
- Local file import through the system file picker (D-pad navigable). The file
  is copied into the asset folder and listed with its size and date.
- Built-in rows are read-only; local-file rows are view/delete only, so a
  rename cannot orphan the imported file.
- New Download all:
  - shows download progress;
  - tries the configured proxy port first and then falls back to a direct
    connection;
  - refreshes every file size and modification time afterwards;
  - replaces the final file only after the temporary download succeeds.

### Verification

- 184 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on an API 37 TV emulator:
  - built-in asset rows with size and date;
  - geo source change and persistence across pages;
  - adding, editing and deleting a URL asset;
  - empty-field validation and error placement;
  - local-file import through DocumentsUI with D-pad, and deletion;
  - metadata refresh after Download all;
  - the phone-pairing QR and 6-digit code from the URL editor.
- `UserAssetEditorValidationTest` covers required fields, duplicate names,
  valid input and file-name sanitizing; `TvNavigatorTest` covers asset-editor
  route restoration.

### Known limitations

- The full pairing handoff that fills the asset URL field after scanning was
  not verified end to end.
- The partial-failure message for Download all was not verified.
- Importing a file from a phone is not implemented; local files come from the
  system picker.
- Settings, backup/WebDAV, logs, about and update checks are not implemented
  yet.
- Not yet verified on a physical TV or phone, API 26-36, RTL, TalkBack, 4K or
  1.3x font scale.

### Installation

- Regular users should download `RoamTV_0.04_universal.apk`; F-Droid users
  should download `RoamTV_0.04-fdroid_universal.apk`.
- Users on v0.03 can upgrade directly; the source `versionCode` is 4 and the
  Play Store APK manifest code is 4,000,004.
- Uninstall any previous debug build first; debug and release builds use
  different signing keys.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
