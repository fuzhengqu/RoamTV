# RoamTV v1.10 / 电视首页与操作改版

## 中文

### 主要更新

- 首页重新布局，去掉右上角的“连接”按钮和三点菜单。
  - 顶部只保留状态、当前节点名、实时速度和搜索。
  - 列表上方提供“导入”“添加节点”“批量”，批量操作集中在单独的对话框中。
  - 右侧操作栏显示当前预览节点的全部操作：连接/断开、测试、编辑配置、分享二维码、更新订阅、删除。
- 浏览与连接分离。
  - 方向键移动只预览节点，不再切换或重连。
  - 在节点上按 OK 只把焦点移到右侧“连接”按钮；只有点“连接”才会更新当前节点并连接。
- 右侧操作栏改为紧凑网格，所有操作在 1080p 下一屏可见并可聚焦；切换预览节点时自动回到顶部。
- 修复焦点问题。
  - 在设置页按左键会回到侧栏“设置”，不再跳到“路由设置”。
  - 节点和侧栏的 3dp 焦点圈上沿不再被列表视口裁掉。
  - 侧栏根页面按 Back 回首页，首页按 Back 才退出。
- “启用速度显示”改为“首页显示实时速度”。
  - 代理核心运行时采样代理/直连速度，在首页顶部显示 `↑/↓` 数值。
  - 该设置只控制首页显示，不再触发核心重载。
- 手机配对导入。
  - 删除电视和手机页面上的无用“验证码”。
  - 同一个二维码会话可以连续发送多个配置；电视显示“已导入 N 项”，点“完成”才结束。
  - 导入后返回首页会聚焦到刚导入的节点。
- 未连接时允许删除当前选中的配置；运行中仍禁止删除正在连接的配置，删除后自动选择同组的下一个节点。

### 真实电视验证

设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，1920×1080 逻辑分辨率。

- 首页新布局、右侧操作栏、紧凑网格和全部操作均可显示和聚焦。
- 在未连接状态浏览节点时状态保持“未连接”；OK 只移动焦点到“连接”。
- 设置页按左键回到“设置”；从设置按 Back 回首页。
- 第一张节点卡片的焦点圈上沿完整显示。
- 批量操作对话框可打开，包含测速、排序、更新订阅和清理操作。
- 连接本地 SOCKS 测试配置后，首页顶部显示：
  - `代理 ↑ 129.0 B/s ↓ 19.0 B/s`
  - `直连 ↑ 2.6 KB/s ↓ 5.8 KB/s`
- 未连接时删除当前选中节点成功，节点数从 4 回到 3。
- 配对弹窗已去掉验证码，显示“用手机相机扫码，可连续发送多个配置”和过期倒计时。

### 验证

- `lintPlaystoreDebug` 通过，`assemblePlaystoreDebug` 和签名 release 通过。
- 发布 APK 为 `armeabi-v7a`，`versionName=1.10`，manifest `versionCode=4,000,110`。

### 已知限制 / Not run

- 物理手机连续扫码导入未执行；服务端连续两次上传由 JVM 测试覆盖。
- 720p、4K、阿拉伯语 RTL、1.3x 字体下的新首页未逐一验证。
- 首页按 Back 退出应用、API 27–35、TalkBack、WebDAV 真实服务器、TV 分享目标和 root 模式未验证。

### 安装说明

- 普通用户下载 `RoamTV_1.10_armeabi-v7a.apk` 或 `RoamTV_1.10_universal.apk`。

  APK 的实际 manifest code 为 4,000,110。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.10-source.zip`。

## English

### Highlights

- Reworked the Home screen and removed the top-right Connect button and
  overflow menu.
  - The top band now shows status, the active node name, live speed and
    search only.
  - The list header provides Import, Add node and Batch; batch actions live in
    one explicit dialog.
  - The action pane shows every action for the previewed node: Connect /
    Disconnect, Test, Edit, Share QR, Update subscription and Delete.
- Browsing is separate from connecting.
  - Moving the cursor only previews a node and never switches or reconnects.
  - OK on a node moves focus to the pane's Connect button; only Connect
    changes the active node and starts or reloads the tunnel.
- The action pane uses a compact grid so every action is visible and focusable
  at 1080p; the pane resets to the top when the preview changes.
- Focus fixes.
  - Left from Settings returns to the Settings rail item instead of Routing.
  - The top edge of the 3dp node/rail focus ring is no longer clipped.
  - Back from a rail root returns Home; only Back at Home leaves the app.
- "Enable speed display" is now "Show speed on Home".
  - The running core samples proxy and direct speeds and the Home top band
    shows `up/down` values.
  - The setting is UI-only and no longer reloads the core.
- Phone pairing.
  - Removed the unused verification code from the TV and phone page.
  - One QR session accepts multiple configurations; the TV shows
    "Imported N item(s)" and a Done button.
  - Returning Home focuses the last imported node.
- A disconnected app can now delete the selected profile. The active profile
  remains protected, and deleting the selection moves it to a surviving node.

### Real TV verification

Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, 1920x1080
logical resolution.

- The new Home layout, action pane, compact grid and all actions render and
  focus correctly.
- While disconnected, browsing leaves the status Disconnected; OK only moves
  focus to Connect.
- Left from Settings returns to the Settings rail item; Back returns Home.
- The first node's focus ring top edge is fully visible.
- The Batch dialog opens with test, sort, subscription update and cleanup
  actions.
- With a local SOCKS test profile connected, the Home header showed:
  - `Proxy ↑ 129.0 B/s ↓ 19.0 B/s`
  - `Direct ↑ 2.6 KB/s ↓ 5.8 KB/s`
- Deleting the selected profile while disconnected succeeded and the node count
  returned from 4 to 3.
- The pairing dialog has no verification code and shows the scan hint and
  countdown.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- The published APK is `armeabi-v7a` with `versionName=1.10` and manifest
  `versionCode=4,000,110`.

### Known limitations / Not run

- Multi-import from a physical phone was not run; two sequential uploads are
  covered by JVM tests.
- The new Home layout was not checked at 720p, 4K, Arabic RTL or 1.3x font.
- Back at Home, API 27-35, TalkBack, a live WebDAV server, TV share targets and
  root mode were not verified.

### Installation

- Regular users should download `RoamTV_1.10_armeabi-v7a.apk` or
  `RoamTV_1.10_universal.apk`.
- Users on v1.03 can upgrade directly; the source `versionCode` is 110 and the
  Play Store APK manifest code is 4,000,110.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.10-source.zip`.
