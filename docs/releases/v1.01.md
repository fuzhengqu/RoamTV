# RoamTV v1.01 / 更新检查修复

## 中文

### 主要更新

- 更新检查现在按**版本号最高**选择候选版本，不再依赖 GitHub 返回顺序。
- 「检查预发布版本」开关语义明确：
  - 关闭：只检查正式版；
  - 开启：正式版和预发布版都参与，选择版本号最高者。
- 始终排除草稿版本。
- 版本号相同时正式版优先，再按发布时间较新者优先。
- 更新弹窗显示「预发布版」标记。
- 没有当前设备兼容的 APK 时显示提示并禁用「Update now」。
- APK 选择改为精确 ABI 优先、universal 兜底，避免 x86 设备误选 x86_64。
- 版本号解析兼容 `v1.01`、`1.01-beta`、`1.01+build` 等形式。

### 验证

- 200 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- `UpdateCheckerManagerTest` 覆盖正式版/预发布版选择、乱序发布、草稿过滤、同版本 tie-break、JSON 字段映射和 tag 后缀容错。
- 更新界面的模拟器冒烟测试未执行，因为收尾阶段没有可用模拟器/设备。

### 安装说明

- 普通用户下载 `RoamTV_1.01_universal.apk`；F-Droid 用户下载
  `RoamTV_1.01-fdroid_universal.apk`。
- 已安装 v1.00 的用户可以直接升级；源码 `versionCode` 为 101，Play Store
  APK 的实际 manifest code 为 4,000,101。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.01-source.zip`。

## English

### Highlights

- Update checks now select the **highest version** instead of relying on the
  GitHub response order.
- The pre-release switch now has clear semantics:
  - Off: stable releases only;
  - On: stable and pre-release releases both participate, and the highest
    version wins.
- Draft releases are always excluded.
- Equal versions prefer the stable release, then the newer publication date.
- The update dialog shows a "Pre-release" badge.
- When no compatible APK exists for the device, the dialog shows a message and
  disables "Update now".
- APK selection prefers an exact ABI asset and falls back to universal,
  preventing an x86 device from picking x86_64.
- Version parsing supports `v1.01`, `1.01-beta` and `1.01+build`.

### Verification

- 200 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- `UpdateCheckerManagerTest` covers stable/pre-release selection, out-of-order
  publication, draft filtering, equal-version tie-breaks, JSON field mapping
  and tag suffix tolerance.
- The update screen was not smoke-tested on an emulator because no emulator or
  device was available at the end of the pass.

### Installation

- Regular users should download `RoamTV_1.01_universal.apk`; F-Droid users
  should download `RoamTV_1.01-fdroid_universal.apk`.
- Users on v1.00 can upgrade directly; the source `versionCode` is 101 and the
  Play Store APK manifest code is 4,000,101.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.01-source.zip`.
