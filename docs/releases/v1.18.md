# RoamTV v1.18 / v2rayNG 2.4.3 功能跟进

## 中文

### 主要更新

- **xdrive 传输**：在现有传输协议下拉框中增加 `xdrive`。
  - 支持 Google Drive、S3、template 和 local 服务；
  - 支持远程目录、逗号分隔密钥和额外 JSON（s3、template、xmux 等）；
  - xdrive 强制启用 Mux，并按 Xray 允许范围修正并发参数；
  - xdrive 下自动移除 VLESS `flow`，避免核心拒绝配置；
  - 复用现有节点编辑器，不新增页面、不改变 v1.14 布局和操作流程。
- **代理链成员列表存储**：新增 `proxyChainProfileList`，备注中包含逗号时不再断链；旧逗号字符串会做一次兼容迁移。
- **路由规则 ID 去重**：导入或加载时修复空 ID/重复 ID，保留规则顺序，不删除规则。

### 上游范围

- 基线仍为 v2rayNG **2.3.15** 稳定版；本次跟进 **2.4.3 pre-release** 中适合 TV 客户端的协议和稳定性改动。
- 不合并上游 Android TV/手机 UI 重构、订阅信息框、Hy2 端口跳转等 UI-only 或无效协议设置。
- DNS 地区校验/并行查询/serve-stale、HEV 2.20.0 和订阅单条更新留待单独评估。

### 验证

- 224 个 JVM 单元测试通过，0 失败。
- `lintPlaystoreDebug` 通过；`assemblePlaystoreDebug` 通过。
- API 36 电视模拟器 1080p：
  - xdrive 节点可通过 `type=xdrive` 导入，编辑器显示服务、密钥、远程目录和额外 JSON；
  - 首行焦点环和 v1.14 布局保持正常；
  - 代理链列表和路由 ID 修复由 JVM 测试覆盖。
- 物理电视安装验证在发布前补充；如电视正在使用，不覆盖安装。

### 已知限制

- 没有真实 xdrive 存储服务，未做真实上传/下载连接。
- 代理链迁移只能尽力拆分旧逗号字符串；新编辑使用列表后不会再受逗号影响。
- DNS 新功能、HEV 2.20.0、订阅 UI 变更尚未合并。

### 安装说明

- 普通用户下载 `RoamTV_1.18_armeabi-v7a.apk` 或 `RoamTV_1.18_universal.apk`。
- 已安装 v1.17 的用户可以直接升级；源码 `versionCode` 为 118。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.18-source.zip`。

## English

### Highlights

- **xdrive transport**: `xdrive` is now in the existing network dropdown.
  - Google Drive, S3, template and local services;
  - remote folder, comma-separated secrets and extra JSON (s3, template,
    xmux, …);
  - xdrive forces Mux and coerces concurrency into Xray's accepted ranges;
  - VLESS `flow` is removed under xdrive so the core accepts the config;
  - reuses the existing editor; no new screen and no change to the v1.14 layout
    or operation flow.
- **Proxy-chain member list storage**: `proxyChainProfileList` preserves remarks
  containing commas; the legacy comma string is migrated once.
- **Routing rule ID uniqueness**: blank or duplicate IDs are repaired on load
  or import, preserving order and never dropping rules.

### Upstream scope

- The stable baseline remains v2rayNG **2.3.15**. Suitable protocol and
  stability changes from the **2.4.3 pre-release** were reviewed and ported.
- Upstream phone/Android TV UI refactors, subscription info boxes and the Hy2
  port-hopping setting are not merged.
- DNS region/parallel/stale, HEV 2.20.0 and single-subscription update remain
  separate evaluations.

### Verification

- 224 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` and `assemblePlaystoreDebug` pass.
- API 36 TV emulator at 1080p:
  - an xdrive profile imported with `type=xdrive` shows service, secrets,
    remote folder and extra JSON in the editor;
  - the first-row focus ring and v1.14 layout remain intact;
  - proxy-chain and routing-ID fixes are covered by JVM tests.
- Physical TV installation will be recorded before release; the TV is not
  overwritten while in use.

### Known limitations

- No live xdrive storage service was available, so no real upload/download was
  exercised.
- Legacy proxy-chain migration can only split the old comma string best-effort;
  new edits always use the list.
- DNS features, HEV 2.20.0 and subscription UI changes are not merged.

### Installation

- Regular users should download `RoamTV_1.18_armeabi-v7a.apk` or
  `RoamTV_1.18_universal.apk`.
- Users on v1.17 can upgrade directly; the source `versionCode` is 118.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.18-source.zip`.
