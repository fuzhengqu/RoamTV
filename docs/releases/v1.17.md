# RoamTV v1.17 / v2rayNG 协议与功能跟进

## 中文

### 主要更新

- **MASQUE (+WARP)**：新增协议类型、`masque://` 解析/导出、WARP 密钥、本地地址、remoteDNS、Host/Path、请求 headers 和 h2/h3 ALPN。
  - 复用现有节点类型选择器和编辑器，不改变 v1.14 页面布局与操作流程；
  - 由内置 Xray 26.11.9 的 MASQUE transport 承载。
- **Custom outbound JSON 导入**：支持直接导入单个 Xray outbound JSON（`{"protocol":...}`），保存原始 outbound 并注入统一配置。
- **路由规则集 URL 导入**：从剪贴板/二维码导入规则集时，如果内容是 HTTP/HTTPS 地址，会先下载 JSON 再导入。
- **莫奈动态色彩**：设置页新增“开启莫奈取色”开关；Android 12+ 使用系统壁纸配色，关闭或低版本时保持原品牌深色。只改变颜色，不改变布局、焦点和操作。
- **安全与稳定性**：
  - 订阅自定义 headers 和 URL 内嵌凭据不再跨域名重定向发送；
  - 禁止 HTTPS 重定向到 HTTP；
  - 自定义 header 日志只记录名称，不记录值；
  - 不支持的 `v2rayn://` 条目只跳过该项，不再导致整批导入失败。

### 上游范围

- 基线仍为 v2rayNG **2.3.15** 稳定版；本次同时审查并移植了 **2.4.1 pre-release** 中的协议、导入、主题和安全改动。
- 不移植上游的手机/TV 启动器 UI 重构、悬浮药丸标签、snackbar 等界面改动。
- 新增 `docs/UPSTREAM_V2RAYNG.md` 功能矩阵，并设置每周一次的上游检查任务。

### 验证

- 214 个 JVM 单元测试通过，0 失败。
- `lintPlaystoreDebug` 通过；`assemblePlaystoreDebug` 通过。
- API 36 电视模拟器 1080p：
  - MASQUE 类型出现在现有添加配置对话框中，编辑器首行焦点环完整；
  - 自定义 outbound JSON 导入后出现在首页节点列表；
  - 动态色彩开关可用，开启后整个界面切换为系统配色，布局不变；
  - 设置/更多/首页仍保持 v1.14 基线。
- 已在 Sony BRAVIA（Android 12，1920×1080，`armeabi-v7a`）从 v1.16 覆盖升级到 v1.17：
  - 3 个节点和订阅数据保留，未连接、未修改节点；
  - 关于页显示 v1.17 / Xray 26.11.9；
  - 动态色彩开启/关闭均正常，布局和焦点没有移动；测试后已恢复为关闭并让电视休眠。

### 已知限制

- 内置 Xray 没有 Hysteria2/TUIC 出站；Hysteria2 仍只保留编辑/分享解析。
- 没有真实 MASQUE/WARP 服务器，本次只验证配置生成、解析和 UI；未做真实连接。
- 订阅用量信息已解析但未增加上游的用量信息框（UI-only）。
- 代理链备注含逗号的存储迁移、Root 热点 DNS 修复仍在功能矩阵中标记为待移植。

### 安装说明

- 普通用户下载 `RoamTV_1.17_armeabi-v7a.apk` 或 `RoamTV_1.17_universal.apk`。
- 已安装 v1.16 的用户可以直接升级；源码 `versionCode` 为 117。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.17-source.zip`。

## English

### Highlights

- **MASQUE (+WARP)**: new protocol type, `masque://` parse/export, WARP keys,
  local address, remoteDNS, Host/Path, request headers, and h2/h3 ALPN.
  - Reuses the existing type picker and server editor; the v1.14 layout and
    operation flow are unchanged.
  - Carried by the bundled Xray 26.11.9 MASQUE transport.
- **Custom outbound JSON import**: imports a single Xray outbound object
  (`{"protocol":...}`), stores the raw outbound and injects it into the unified
  config.
- **Ruleset URL import**: when clipboard/QR ruleset content is an HTTP/HTTPS
  URL, the JSON is downloaded first.
- **Monet dynamic colour**: new Settings switch. Android 12+ uses the system
  wallpaper palette; unsupported versions and the off state keep the brand
  dark palette. Colours change only; layout, focus and actions do not.
- **Security and stability**:
  - subscription custom headers and embedded credentials are no longer sent
    across cross-origin redirects;
  - HTTPS-to-HTTP redirects are rejected;
  - custom header logs contain names only, not values;
  - an unsupported `v2rayn://` entry is skipped instead of failing the batch.

### Upstream scope

- The stable baseline remains v2rayNG **2.3.15**. Protocol, import, theme and
  security changes from the **2.4.1 pre-release** were reviewed and ported.
- Upstream phone/TV-launcher UI refactors, floating pill tabs and snackbars are
  not ported.
- `docs/UPSTREAM_V2RAYNG.md` records the feature matrix; a weekly upstream
  review task is scheduled.

### Verification

- 214 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` and `assemblePlaystoreDebug` pass.
- API 36 TV emulator at 1080p:
  - MASQUE appears in the existing Add config dialog; its first editor row has
    a complete focus ring;
  - a custom outbound JSON import appears in the Home profile list;
  - the dynamic colour switch changes the palette without moving the layout;
  - Home, Settings and More keep the v1.14 baseline.
- Upgraded the Sony BRAVIA (Android 12, 1920x1080, `armeabi-v7a`) from v1.16
  to v1.17 in place:
  - all 3 profiles and subscriptions were kept; nothing was connected or
    modified;
  - About shows v1.17 / Xray 26.11.9;
  - dynamic colour was toggled on and off without moving the layout or focus,
    then restored to off and the TV was put back to sleep.

### Known limitations

- The bundled Xray core has no Hysteria2/TUIC outbound; Hysteria2 remains
  editor/share-parse only.
- No live MASQUE/WARP server was available, so only config generation, parsing
  and UI were verified.
- Subscription usage is parsed but the upstream usage info box (UI-only) is not
  added.
- Proxy-chain remarks containing commas and the root hotspot DNS fix remain
  pending in the feature matrix.

### Installation

- Regular users should download `RoamTV_1.17_armeabi-v7a.apk` or
  `RoamTV_1.17_universal.apk`.
- Users on v1.16 can upgrade directly; the source `versionCode` is 117.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.17-source.zip`.
