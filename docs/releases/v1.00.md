# RoamTV v1.00 / 稳定版

## 中文

### 概述

RoamTV 1.00 是面向 Android TV 的完整稳定版本。所有功能以遥控器为第一输入，
采用单一 Activity、Compose for TV、固定深色主题和 5% overscan 安全区。

### 功能

- 节点与分组：服务器列表、策略组、代理链、搜索、删除、排序、测速、分享。
- 订阅：订阅列表、编辑器、增量更新、全部更新、自动更新相关设置。
- 路由与 DNS：路由规则、规则集、域名策略、远程/直连 DNS、DNS 映射。
- 分应用代理：应用列表、启用/绕过模式、批量选择、剪贴板导入导出。
- 资源文件：内置 GeoIP/GeoSite、来源切换、URL/本地文件、下载全部。
- 设置：界面、VPN、核心、Mux、Fragment、Observatory、高级和运行模式。
- 备份与恢复：本地 zip、WebDAV 配置、分享、修复配置存储。
- 信息与维护：日志、关于、GPL/第三方许可证、翻译者、更新检查。
- 导入：剪贴板、文本、文件、手机配对和 `roamtv://` / `ACTION_SEND`。
- 连接模式：VPN、仅代理、root 模式及局域网共享分支保留。
- 合规：应用内法律声明；每个 Release 附带源码归档。

### 验证

- 192 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors。
- `assemblePlaystoreDebug` 和 release 构建通过。
- 已在 Android 17（API 37）模拟器上验证主要 TV 流程，包括首页、节点/分组、
  订阅、路由、分应用、资源文件、设置、备份/恢复、日志、关于、更新和 1.3x
  字体布局。
- 每个 Release 包含 22 个资产：APK、`.sig`、公钥和 `RoamTV-<tag>-source.zip`。

### 已知限制 / Not run

- 720p、4K、RTL、TalkBack、API 26–36 和物理电视/手机验证未完成。
- 1.3x 字体下的完整焦点遍历和全部页面未逐一验证。
- 主机重启后 TV 模拟器系统服务不稳定，部分截图和焦点检查无法重复。
- WebDAV 上传/下载、TV 分享目标、root 模式、服务运行中离开设置页的单次重启
  未验证。
- 这些项目已在 `docs/TV_FEATURE_MATRIX.md` 中标记为未验证；不影响代码和
  发布产物的完整性。

### 安装

- 普通用户下载 `RoamTV_1.00_universal.apk`；F-Droid 用户下载
  `RoamTV_1.00-fdroid_universal.apk`。
- 源码 `versionCode` 为 100，Play Store APK 的 manifest code 为 4,000,100。
- 已安装 v0.20 的用户可以升级。
- 每个 APK 都有 `.sig`；公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.00-source.zip`。

## English

### Overview

RoamTV 1.00 is the complete stable Android TV release. Every feature is
remote-first, built on a single Activity, Compose for TV, a fixed dark theme and
a 5% overscan-safe layout.

### Features

- Servers and groups: list, policy groups, proxy chains, search, delete, sort,
  latency tests and sharing.
- Subscriptions: list, editor, incremental and full updates, auto-update
  settings.
- Routing and DNS: rules, rulesets, domain strategy, remote/direct DNS and DNS
  mappings.
- Per-app proxy: app list, proxy/bypass modes, bulk selection and clipboard
  import/export.
- User assets: built-in GeoIP/GeoSite, source switch, URL/local files and
  Download all.
- Settings: UI, VPN, core, Mux, Fragment, Observatory, advanced and run modes.
- Backup and restore: local zip, WebDAV config, sharing and profile-storage
  repair.
- Information and maintenance: logs, about, GPL/third-party licenses,
  translators and update check.
- Import: clipboard, text, file, phone pairing, `roamtv://` and `ACTION_SEND`.
- Connection modes: VPN, proxy-only and root-mode/LAN-sharing branches are
  preserved.
- Compliance: in-app legal notices; every release carries a source archive.

### Verification

- 192 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors.
- `assemblePlaystoreDebug` and the release build pass.
- Major TV flows were verified on an Android 17 (API 37) emulator, including
  Home, servers/groups, subscriptions, routing, per-app, assets, settings,
  backup/restore, logs, about, update and 1.3x font layouts.
- Each release has 22 assets: APKs, `.sig` files, the public key and
  `RoamTV-<tag>-source.zip`.

### Known limitations / Not run

- 720p, 4K, RTL, TalkBack, API 26-36 and physical TV/phone verification are not
  complete.
- Full 1.3x focus traversal and every screen were not verified individually.
- TV emulator system services were unstable after the host restart, so some
  screenshots and focus checks could not be repeated.
- WebDAV upload/download, TV share targets, root mode and the single restart
  when leaving Settings with a running service are unverified.
- These items are recorded as unverified in `docs/TV_FEATURE_MATRIX.md`; they
  do not affect the completeness of the code or release artifacts.

### Installation

- Regular users should download `RoamTV_1.00_universal.apk`; F-Droid users
  should download `RoamTV_1.00-fdroid_universal.apk`.
- The source `versionCode` is 100 and the Play Store APK manifest code is
  4,000,100.
- Users on v0.20 can upgrade directly.
- Every APK has a `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.00-source.zip`.
