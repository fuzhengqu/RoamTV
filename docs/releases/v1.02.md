# RoamTV v1.02 / Android TV 布局修复

## 中文

### 主要更新

- 修复真实 Android TV / API 26 上侧栏主菜单项不显示的问题。
  - 侧栏内容改为由 `TvRailLayout` 传入实际可用高度，避免权重列在部分 TV 布局中坍缩为零。
  - 主菜单在 720p、1080p、4K 和 1.3x 字体下均可显示和滚动。
- 修复设置行、更新页和 More 对话框在部分 TV 上只显示第一项、其余内容被推到屏外的问题。
  - 恢复固定的行高和单行标签，避免 `heightIn` 配合 `fillMaxSize` 在普通 Column 中无限扩展。
- 保留 API 26 的 D-pad、返回栈、设置、更新检查、备份和资源文件行为。
- 新增 Android TV 系统镜像验证：
  - API 26 TV AVD：启动、侧栏、设置、更新、More 对话框、路由编辑器和资源文件。
  - API 36 TV AVD：1280×720、1920×1080、3840×2160。
  - 720p 阿拉伯语 RTL 和 1.3x 字体抽查通过。
- 更新检查仍按最高版本选择正式版/预发布版，并显示预发布标记。

### 验证

- 200 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 26 和 API 36 的真实 Android TV 系统镜像上完成上述布局与导航验证。

### 已知限制 / Not run

- API 27–35 未逐一验证。
- TalkBack 的朗读顺序和完整语义遍历未验证。
- 1.3x 字体下的全部页面和对话框未逐一验证。
- 物理电视、WebDAV 真实服务器、TV 分享目标、root 模式和服务运行中离开设置页的重启未验证。

### 安装说明

- 普通用户下载 `RoamTV_1.02_universal.apk`；F-Droid 用户下载
  `RoamTV_1.02-fdroid_universal.apk`。
- 已安装 v1.01 的用户可以直接升级；源码 `versionCode` 为 102，Play Store
  APK 的实际 manifest code 为 4,000,102。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.02-source.zip`。

## English

### Highlights

- Fixed the missing primary rail items on real Android TV / API 26.
  - `TvRailLayout` now passes the actual available height to the rail, so the
    weighted column cannot collapse to zero on some TV layouts.
  - The rail works and scrolls at 720p, 1080p, 4K and 1.3x font scale.
- Fixed settings rows, the update screen and the More dialog showing only the
  first item on some TVs and pushing the rest off-screen.
  - Fixed row heights and single-line labels avoid `heightIn` plus
    `fillMaxSize` expanding indefinitely in a plain Column.
- Preserved API 26 D-pad, back stack, settings, update checks, backup and asset
  behavior.
- Added real Android TV system-image verification:
  - API 26 TV AVD: launch, rail, Settings, Update, More dialog, routing editor
    and asset files.
  - API 36 TV AVD: 1280x720, 1920x1080 and 3840x2160.
  - 720p Arabic RTL and 1.3x spot checks pass.
- Update checks still select the highest stable/pre-release version and show
  the pre-release badge.

### Verification

- 200 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- The layout and navigation checks above ran on real Android TV API 26 and
  API 36 system images.

### Known limitations / Not run

- API 27-35 were not verified individually.
- TalkBack spoken order and full semantic traversal were not verified.
- Not every screen and dialog was checked at 1.3x.
- Physical TV, a live WebDAV server, TV share targets, root mode and the
  restart when leaving Settings with a running service remain unverified.

### Installation

- Regular users should download `RoamTV_1.02_universal.apk`; F-Droid users
  should download `RoamTV_1.02-fdroid_universal.apk`.
- Users on v1.01 can upgrade directly; the source `versionCode` is 102 and the
  Play Store APK manifest code is 4,000,102.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.02-source.zip`.
