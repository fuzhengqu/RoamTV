# RoamTV v1.03 / 设置应用与连接保持

## 中文

### 主要更新

- 修复在已连接状态下离开设置页面会断开 VPN 的问题。
  - 设置变更现在通过原地重载代理核心生效：Android 服务、VPN 接口和通知保持运行，
    界面状态保持“已连接”。
  - 重载会重新构建核心配置，使新的 DNS、路由、TUN 和核心选项立即生效。
- 修复设置写入与重载的时序：先保存设置，再请求核心重载，重载必定读取新值。
- 仅影响界面的设置（如“删除配置确认”）不再触发核心重载。
- 设置变更不会启动已经停止的服务；未连接时仅保存设置，下次连接时使用。

### 真实电视验证

- 设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，
  逻辑分辨率 1920×1080。
- 已连接状态进入设置、切换“启用速度显示”、离开设置：
  - 日志显示 `Restart service`、`Core reload start...` 和 `Core reload finished`；
  - 代理核心重新启动，`tun0` 保持存在，界面保持“已连接”，没有 `agentDisconnect`。
- 切换仅界面设置后离开：没有核心重载，连接保持不变。
- 未连接状态下修改核心设置并离开：保持“未连接”，核心与 VPN 服务均未启动。

### 验证

- 204 个 JVM 单元测试通过（新增 `SettingsChangeManagerTest`）。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 和签名 release 通过。
- 发布 APK 为 `armeabi-v7a`，`versionName=1.03`，manifest `versionCode=4000103`。

### 已知限制 / Not run

- API 27–35 未逐一验证。
- TalkBack 朗读顺序和完整语义遍历未验证。
- 1.3x 字体下的全部页面和对话框未逐一验证。
- WebDAV 真实服务器、TV 分享目标、root 模式和物理手机配对未验证。

### 安装说明

- 普通用户下载 `RoamTV_1.03_armeabi-v7a.apk` 或 `RoamTV_1.03_universal.apk`。
- 已安装 v1.02 的用户可以直接升级；源码 `versionCode` 为 103，Play Store
  APK 的实际 manifest code 为 4,000,103。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。
- 源码归档为 `RoamTV-v1.03-source.zip`。

## English

### Highlights

- Fixed the VPN disconnecting when leaving Settings while connected.
  - A settings change now applies by reloading the proxy core in place: the
    Android service, VPN interface and notification stay up, and the UI keeps
    showing Connected.
  - The reload rebuilds the core config, so new DNS, routing, TUN and core
    options take effect immediately.
- Fixed the ordering between saving and reloading: the setting is persisted
  first, then the reload is requested, so the core always reads the new value.
- UI-only settings (for example the delete confirmation) no longer trigger a
  core reload.
- A settings change never starts a stopped service; while disconnected it only
  saves the value for the next connection.

### Real TV verification

- Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, logical
  resolution 1920x1080.
- While connected, opened Settings, toggled “Show speed”, and left Settings:
  - the log shows `Restart service`, `Core reload start...` and
    `Core reload finished`;
  - the proxy core restarted, `tun0` stayed up, the UI stayed Connected, and no
    `agentDisconnect` occurred.
- Leaving after a UI-only setting change: no core reload, connection unchanged.
- Changing a core setting while disconnected and leaving: stayed Disconnected;
  neither the core nor the VPN service started.

### Verification

- 204 JVM unit tests pass (including the new `SettingsChangeManagerTest`).
- `lintPlaystoreDebug` reports 0 errors; `assemblePlaystoreDebug` and the
  signed release build pass.
- The published APK is `armeabi-v7a` with `versionName=1.03` and manifest
  `versionCode=4000103`.

### Known limitations / Not run

- API 27-35 were not verified individually.
- TalkBack spoken order and full semantic traversal were not verified.
- Not every screen and dialog was checked at 1.3x.
- A live WebDAV server, TV share targets, root mode and physical phone pairing
  were not verified.

### Installation

- Regular users should download `RoamTV_1.03_armeabi-v7a.apk` or
  `RoamTV_1.03_universal.apk`.
- Users on v1.02 can upgrade directly; the source `versionCode` is 103 and the
  Play Store APK manifest code is 4,000,103.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.03-source.zip`.
