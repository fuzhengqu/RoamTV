# RoamTV v1.13 / 按钮、弹窗与返回焦点修复

## 中文

### 主要更新

- 按钮文字完整居中。
  - 移除了次要按钮的 88dp 最小宽度，按钮宽度严格由文字 + 左右 16dp 内边距决定；
  - “导入”“添加节点”“批量”等短按钮的文字不再偏向左侧；
  - 按钮内容区占满高度并垂直居中，连接、测试、编辑、二维码、更新订阅、删除的文字均在按钮中央。
- 首页右侧操作栏重新分布。
  - 连接/断开保持整行宽；
  - 测试/编辑配置、二维码/更新订阅使用两列等宽布局，文字居中；
  - 删除整行宽；左右留白一致，不再在右侧留下大块空白。
- 弹窗第一项焦点圈不再被裁。
  - 添加节点、批量操作、语言选择、选项弹窗等所有带滚动列表的弹窗增加 6dp 顶部内容留白；
  - 第一项焦点圈上沿完整显示。
- 返回焦点修复。
  - 引入 `SaveableStateHolder`，按路由保存页面状态；
  - 更多页记住最后选中的入口，从备份/更新/关于返回时回到对应行，而不是 Logcat；
  - 订阅分组记住最后聚焦的订阅；
  - 首页从节点编辑器返回时回到原节点；
  - 分应用设置在首次打开时自动聚焦第一个应用。

### 真实电视验证

设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，1920×1080 逻辑分辨率。

- 首页“导入”“添加节点”“批量”文字居中；
- 右侧连接整行、测试/编辑和二维码/更新订阅两列等宽、删除整行，左右留白一致；
- 添加节点和批量操作弹窗第一项焦点圈上沿完整；
- 更多 → 备份/检查更新/关于 → 返回，焦点分别回到备份/检查更新/关于；
- 订阅分组、路由设置（域名策略）、资源文件的第一项焦点圈完整；
- 首页进入节点编辑器后返回，焦点回到原节点；
- 分应用设置首次打开时聚焦第一个应用。

## English

### Highlights

- Button labels are now centered on both axes.
  - The 88dp minimum width was removed from secondary buttons; width is now
    text + 16dp horizontal padding;
  - short buttons such as Import, Add node and Batch no longer push their text
    to the left;
  - the content box fills the button height and centers vertically, so Connect,
    Test, Edit, QR, Update subscription and Delete are all centered.
- Reworked the right-hand action layout.
  - Connect/Disconnect keeps the full row;
  - Test/Edit and QR/Update subscription use two equal-width columns with
    centered labels;
  - Delete keeps the full row, with equal left and right margins.
- The first focus ring in scrollable dialogs is no longer clipped.
  - Add node, Batch, language and option dialogs now have 6dp top content
    padding inside their scroll lists.
- Back focus restoration.
  - Added `SaveableStateHolder` keyed by route;
  - the More page remembers its last selected entry, so Backup/Update/About
    return to their row instead of Logcat;
  - Subscriptions remembers the last focused subscription;
  - Home returns from a node editor to the original node;
  - Per-app focuses the first app when first opened.

### Real TV verification

Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, 1920x1080
logical resolution.

- Home's Import, Add node and Batch labels are centered.
- The action pane shows a full-width Connect, two equal columns for
  Test/Edit and QR/Update, and a full-width Delete.
- Add node and Batch dialogs show the first item's focus ring fully.
- More -> Backup/Update/About -> Back returns focus to the selected row.
- The first-item focus ring in Subscriptions, Routing (domain strategy) and
  Assets is fully visible.
- Home returns from a node editor to the original node.
- Per-app focuses the first app on first open.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- The published APK is `armeabi-v7a` with `versionName=1.13` and manifest
  `versionCode=4,000,113`.

### Known limitations / Not run

- The language/option dialogs' first-item rings were not screenshotted
  individually (shared top padding was added).
- The final button/dialog layout was not checked at 720p, 4K, Arabic RTL or
  1.3x font.
- Multi-import from a physical phone, TalkBack, a live WebDAV server, TV share
  targets and root mode were not verified.

### Installation

- Regular users should download `RoamTV_1.13_armeabi-v7a.apk` or
  `RoamTV_1.13_universal.apk`.
- Users on v1.12 can upgrade directly; the source `versionCode` is 113 and the
  Play Store APK manifest code is 4,000,113.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.13-source.zip`.
