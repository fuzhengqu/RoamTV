# RoamTV v0.03 / 分应用代理

## 中文

### 主要更新

- 新增 TV 分应用代理设置：应用列表、启用开关、Bypass 模式和批量操作。
- 每个应用行显示应用名、包名、系统应用标记和选中状态。
- 点击应用即可切换是否走代理；列表会保留当前焦点的应用。
- More 菜单提供全选、反选、自动选择代理应用、剪贴板导入和剪贴板导出。
- 支持搜索应用名称或包名。

### 验证情况

- 178 个 JVM 单元测试通过。
- `lintPlaystoreDebug` 0 errors，`assemblePlaystoreDebug` 通过。
- 在 API 37 TV 模拟器上验证了：
  - 应用列表加载（含系统应用标记）
  - 单个应用选中/取消，选中状态和勾选图标更新
  - Enable per-app / Bypass Mode 开关
  - More 菜单的全选、反选、自动选择、导入/导出入口
- `AppSelectionTest` 覆盖反选、普通模式、Bypass 模式和 Google 应用强制选择。

### 已知限制

- 搜索过滤、自动选择、剪贴板导入/导出尚未端到端验证。
- 分应用选择对实际 VPN 连接的影响尚未验证。
- 资源文件、设置、备份、日志、关于和更新检查尚未完成。
- 尚未在物理电视和物理手机上验证；API 26–36、RTL、TalkBack、4K 和
  1.3x 字体尚未验证。

### 安装说明

- 普通用户下载 `RoamTV_0.03_universal.apk`；F-Droid 用户下载
  `RoamTV_0.03-fdroid_universal.apk`。
- 已安装 v0.02 的用户可以直接升级；源码 `versionCode` 为 3，Play Store
  APK 的实际 manifest code 为 4,000,003。
- 如果之前安装过 debug 构建，请先卸载；debug 与 release 签名不同。
- 每个 APK 都有对应的 `.sig`，公钥为 `RoamTV-public-key.asc`。

## English

### Highlights

- New TV per-app proxy settings: app list, enable switch, bypass mode and bulk
  actions.
- Each app row shows the app name, package name, system-app marker and
  selection state.
- Activate an app row to toggle whether it uses the proxy; the focused app is
  resolved by package name after the update.
- The More menu offers select-all, invert, auto-select proxy apps, clipboard
  import and clipboard export.
- Search by app name or package name.

### Verification

- 178 JVM unit tests pass.
- `lintPlaystoreDebug` reports 0 errors and `assemblePlaystoreDebug` passes.
- Verified on an API 37 TV emulator:
  - app-list loading, including system-app markers;
  - toggling an app and updating its check mark/state;
  - Enable per-app and Bypass Mode switches;
  - the More menu entries for select-all, invert, auto-select and import/export.
- `AppSelectionTest` covers invert, normal mode, bypass mode and forced Google
  app selection.

### Known limitations

- Search filtering, auto-select and clipboard import/export were not verified
  end to end.
- The effect of per-app selections on a live VPN connection was not verified.
- User assets, settings, backup, logs, about and update checks are not
  implemented yet.
- Not yet verified on a physical TV or phone, API 26-36, RTL, TalkBack, 4K or
  1.3x font scale.

### Installation

- Regular users should download `RoamTV_0.03_universal.apk`; F-Droid users
  should download `RoamTV_0.03-fdroid_universal.apk`.
- Users on v0.02 can upgrade directly; the source `versionCode` is 3 and the
  Play Store APK manifest code is 4,000,003.
- Uninstall any previous debug build first; debug and release builds use
  different signing keys.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
