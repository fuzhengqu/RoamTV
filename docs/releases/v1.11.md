# RoamTV v1.11 / 电视焦点与按钮布局修复

## 中文

### 主要更新

- 修复焦点效果过大的问题。
  - TV Material3 默认在聚焦时把按钮、设置行、节点行和侧栏项放大到 1.1 倍，并叠加 glow；这是焦点圈遮挡周边、文字被拉开、圈溢出边缘的根因。
  - 现在统一关闭聚焦缩放和 glow，改为 2dp 内缩边框 + 背景色变化，焦点圈不再超出控件本身。
- 按钮布局重做。
  - 按钮文字统一居中；右侧操作栏不再用两等分宽度，改为按文字内容决定宽度。
  - 主操作“连接/断开”保持整行宽，文字居中；测试、编辑、二维码、更新订阅、删除使用紧凑的内容宽度按钮。
  - 按钮最小宽度 88dp，间距 8dp，焦点圈不会互相遮挡。
- 首页右侧操作栏精简。
  - 顶部改为一行“操作 · 节点名”，删除重复的协议、地址、延迟和“未测试”标识。
  - 节点信息只保留在左侧列表；右侧操作区整体上移，更直接。
- “未测试”标识只在节点行中显示有测速结果时出现，未测试节点不再挂冗余徽标。
- 设置页内容列最大宽度 560dp，右侧留出安全边距；设置行的 label/value 不再贴近屏幕边缘，焦点圈完整可见。
- 左侧“更多”移入同一个侧栏列表，位于“设置”之后，与首页、订阅分组、路由设置等完全同级；弹窗和日志/备份/更新/关于内容保持不变。

### 真实电视验证

设备：Sony BRAVIA 4K VH2，Android 12（API 31），`armeabi-v7a`，1920×1080 逻辑分辨率。

- 首页右侧显示单行“操作 · 节点名”，操作区上移。
- 连接按钮文字居中，焦点圈为内缩 2dp，不再放大或遮挡周边。
- 测试/编辑、二维码/更新订阅、删除按钮按内容宽度排列，文字居中，焦点切换不再出现大圈。
- 未测试节点不再显示“未测试”徽标。
- 设置页内容列宽度收紧到 560dp，焦点圈没有贴边或溢出。
- 左侧“更多”与设置等项在同一列表中，间距一致；点击仍打开原有弹窗。

### 验证

- `lintPlaystoreDebug` 通过，`assemblePlaystoreDebug` 和签名 release 通过。

### 已知限制 / Not run

- 720p、4K、阿拉伯语 RTL、1.3x 字体下的新焦点/按钮样式未逐一验证。
- 日志、分应用、资源文件等页面的行样式使用同一组件，但未逐页截图验证。
- 物理手机连续导入、TalkBack、WebDAV 真实服务器、TV 分享目标和 root 模式未验证。

## English

### Highlights

- Fixed the oversized focus effect.
  - TV Material3 scales focused buttons, settings rows, node rows and rail
    items to 1.1x by default and adds a glow. That was the cause of the ring
    covering nearby content, the text spreading apart and the ring overflowing
    the screen edge.
  - Focus scaling and glow are now disabled for these components; a 2dp inset
    border and the focused background carry the focus state.
- Reworked button layout.
  - Button text is centered; the action pane no longer uses two equal-width
    columns, so each button is sized by its content.
  - The primary Connect/Disconnect action remains full width with centered
    text; Test, Edit, QR, Update subscription and Delete use compact
    content-width buttons.
  - Compact buttons have an 88dp minimum width and 8dp gaps, so focus rings
    cannot overlap neighbouring buttons.
- Simplified the Home action pane.
  - The header is one line: "Actions · node name"; duplicate protocol,
    address, latency and "Not tested" text was removed.
  - Node details stay in the left list, and the action area moves up.
- The "Not tested" badge is only shown when a measured latency exists;
  untested rows no longer carry a redundant badge.
- The Settings content column is capped at 560dp, keeping the value away from
  the screen edge and the focus ring fully visible.
- The rail "More" entry now lives in the same list as Home, Subscriptions,
  Routing, Per-app, Assets and Settings, directly after Settings. The dialog
  and its Logs/Backup/Update/About content are unchanged.

### Real TV verification

Device: Sony BRAVIA 4K VH2, Android 12 (API 31), `armeabi-v7a`, 1920x1080
logical resolution.

- Home shows a single-line "Actions · node" header and the action area moved
  up.
- The Connect button text is centered and its focus ring is inset by 2dp with
  no enlargement or overlap.
- Test/Edit, QR/Update subscription and Delete are content-sized, centered and
  do not produce the previous oversized focus ring.
- Untested nodes no longer show a "Not tested" badge.
- The Settings rows are capped at 560dp; the focus ring stays inside the safe
  area without touching the edge.
- The "More" rail entry shares the same list and spacing as Settings; it still
  opens the existing dialog.

### Verification

- 206 JVM unit tests pass with 0 failures.
- `lintPlaystoreDebug` passes; `assemblePlaystoreDebug` and the signed release
  pass.
- The published APK is `armeabi-v7a` with `versionName=1.11` and manifest
  `versionCode=4,000,111`.

### Known limitations / Not run

- The new focus and button styles were not checked at 720p, 4K, Arabic RTL or
  1.3x font.
- Logcat, Per-app and Assets use the same components but were not screenshotted
  page by page.
- Multi-import from a physical phone, TalkBack, a live WebDAV server, TV share
  targets and root mode were not verified.

### Installation

- Regular users should download `RoamTV_1.11_armeabi-v7a.apk` or
  `RoamTV_1.11_universal.apk`.
- Users on v1.10 can upgrade directly; the source `versionCode` is 111 and the
  Play Store APK manifest code is 4,000,111.
- Every APK has a matching `.sig`; the public key is `RoamTV-public-key.asc`.
- The source archive is `RoamTV-v1.11-source.zip`.
